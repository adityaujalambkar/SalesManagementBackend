STEPS TO FOLLOW TO LAUNCH THIS APPLICATION
==============================================
1. Install Docker Desktop in your System

**********************************************
2. Run this docker command [docker build -t {image//any name}] .// here . will specify docker file in current folder 

  "docker build -t image ."

##############################################
3. "docker run -d -p 8080:8080 --name my-spring-app image" //this will run your code on 
http://localhost:8080/
